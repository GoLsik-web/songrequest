# Заказ музыки для Twitch

Локальное приложение: зрители заказывают треки за баллы канала или донат, а
музыка играет в Spotify самого стримера. Когда очередь заканчивается, Spotify
возвращается ровно туда, где стример остановился.

**Работает.** Один `.exe` без установки: скачал, запустил, дальше приложение
проводит по настройке само — обход блокировок, Spotify, Twitch, награда за
баллы, виджет для OBS.

Готовые сборки — на [странице выпусков](../../releases). Обновляется само,
по кнопке в панели.

## Запуск для разработки

```
go run .                      # запустить: своё окно с панелью внутри
go run . -в-браузере          # без окна, панель в браузере (для разбора поломок)
go run . -без-браузера        # не открывать ни окна, ни браузера
go test ./...                 # тесты
```

Панель живёт по адресу `http://127.0.0.1:8977` и в окне программы, и в
браузере — это одна и та же страница. Виджет для OBS остаётся адресом:
`http://127.0.0.1:8977/widget`.

Крестик окна прячет приложение в трей, выход — правой кнопкой по значку возле
часов. Второй запуск .exe не поднимает вторую копию, а показывает окно первой.

Настройки, база и лог лежат в `%APPDATA%\songrequest`.

## Обход блокировок

Из России Spotify не отвечает приложениям, поэтому обход живёт внутри: стример
вставляет в настройках ключ от своего VPN (`vless://`, `trojan://`, `ss://`,
`vmess://`) или ссылку на подписку, а приложение само добывает `xray.exe`,
перебирает серверы и оставляет тот, через который отвечает именно Spotify
(`internal/tunnel`). Через обход идут только наши запросы к Spotify — системный
прокси Windows не трогается, остальной интернет идёт напрямую.

Ключ — секрет: лежит в хранилище паролей Windows, в `config.json` и в архиве
диагностики его нет, в лог не попадает. Настройка для Xray передаётся ему через
стандартный ввод, а не файлом. Ручное поле «Прокси для Spotify» осталось
запасным путём для тех, у кого своя программа обхода. Для стримера всё это
описано в [docs/Инструкция-Обход-блокировок.html](docs/Инструкция-Обход-блокировок.html).

## Сборка релиза

```powershell
.\build.ps1
```

Прогоняет тесты, кладёт `dist\songrequest.exe` и собирает архив с инструкцией
для отправки стримеру. Версия берётся из хеша коммита и видна в панели — по
логу сразу понятно, какая именно сборка стоит у человека.

## Оформление

Панель «Эфир»: одна акцентная краска (кислотный лайм), тёмная тема,
типографика вместо плиток — то, что играет, набрано так, чтобы читаться за
долю секунды в альт-табе. Шрифты (Unbounded, Manrope) и иконки (Lucide)
лежат в `internal/server/web` и вшиты в бинарник: панель работает без
интернета. Черновики обоих вариантов оформления остались в `docs/design`.

## Диагностика на расстоянии

Приложение работает у одного человека, а чинит его другой, поэтому:

- в панели каждая ошибка показана с коротким кодом (`SP-04`), который можно
  продиктовать голосом;
- подробный лог пишется всегда: чинить приходится по одному-единственному
  разу, когда всё сломалось, и просить «включи галочку и повтори» поздно;
- кнопка «Сохранить лог и историю» собирает в один `.zip` лог, историю заказов
  с возвратами баллов, действия в панели, настройки и сведения о системе.
  Ключи доступа и Client ID из архива вырезаются — это проверяется тестом
  в `internal/diag`.

## Что умеет

- **Заказ за баллы канала или донат.** Зритель пишет название или кидает
  ссылку — на Spotify, YouTube, Яндекс.Музыку или VK. Не нашлось или трек не
  подошёл по правилам — баллы возвращаются сами.
- **Заказ плейлиста отдельной наградой.** Цена считается сама и остаётся
  выгоднее поштучного заказа. Плейлист не идёт в эфир сам: ждёт, пока его
  одобрит стример или модератор.
- **Возврат музыки на место.** Очередь кончилась — Spotify возвращается ровно
  туда, где стример остановился, вплоть до места внутри трека.
- **Команды в чате** для стримера и модераторов: очередь, скип (по номеру или
  по названию), возврат скипнутого, громкость, пауза, баны. На каждую команду
  идёт ответ — молчание читается как поломка.
- **Виджет для OBS**: десять оформлений, девять точек привязки в кадре,
  перетаскивание мышью, показ постоянно или по расписанию.
- **Запасной проигрыватель.** Чего нет в Spotify, играется с YouTube через
  yt-dlp и mpv — их приложение добывает само.
- **Обход блокировок внутри приложения.** Вставляешь ключ от своего VPN или
  ссылку на подписку, всё остальное приложение делает само. Через обход идут
  только запросы к Spotify: игра, чат и стрим остаются на прямом канале.

## Бережное отношение к норме запросов Spotify

Client ID стример заводит на своём аккаунте, а норма запросов там тесная —
это главное ограничение всего проекта. Поэтому:

- что играет у стримера, читается из заголовка окна программы Spotify, а не
  спрашивается по сети;
- положение внутри трека приложение считает само и рисует полосу без единого
  запроса;
- играющий заказ проверяется раз в двадцать пять секунд, а конец трека
  ловится точно, по его длительности;
- объявленная Spotify пауза запоминается, и до её конца в сеть не ходит
  ничего.
