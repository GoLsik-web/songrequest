        Программе Spotify прокси не нужен. Она ходит другими адресами, и если музыка у тебя играет без VPN — в ней ничего менять не надо. Блокируют обычно только адреса, по которым работают приложения вроде этого.

        Вход всё равно один раз через VPN. Кнопка «Подключить Spotify» открывает страницу входа в браузере, а браузер про этот прокси не знает. Включи VPN, войди, выключи VPN — дальше приложение живёт на прокси само.
