# 0.62.0 — Telegram-компаньон и обновлённое оформление

## Что нового

- Telegram-компаньон встроен в приложение: отдельная программа и Python не нужны. Настройка находится в **Настройки → Прочее → Telegram-компаньон**; кнопка бота сверху открывает этот раздел.
- В Telegram доступны итоги эфира, номинации, история заказов, карточка для публикации и пульт музыки. Автоматические итоги и уведомления включаются отдельно. Интеграция по умолчанию выключена.
- Свои стили виджета и автоматическое оформление под сцены OBS доступны бесплатно.
- Обновлены значок, заставка запуска и мастер настройки. Улучшены тексты русского и английского интерфейса.

## Исправления

- Ограничен буфер кадров заставки, уменьшен расход памяти при запуске. Выход во время заставки отменяет раскрытие окна.
- Исправлено сохранение и удаление привязок стилей к сценам OBS. Изменения оформления из другого окна и при смене сцены отражаются в редакторе.
- Сохранения настроек выполняются по очереди и передают изменённые поля.
- Telegram принимает управление только от указанного владельца в личном чате. Старые управляющие сообщения и повторно доставленные события не выполняются повторно.
- Токен Telegram хранится в хранилище паролей Windows; личные настройки скрыты в диагностическом архиве.
- Фоновые задачи завершаются до закрытия базы. Исправлены обновление значка одинакового размера и отсутствующая иконка страницы.
- Сборка использует Go 1.26.10 с исправлениями безопасности. Лицензии компонентов доступны в приложении и входят в архив.

## Как подключить Telegram

1. Создай отдельного бота у **@BotFather**, вставь токен в приложение, включи компаньона и сохрани настройки.
2. Открой своего бота и отправь `/id`.
3. Впиши полученный ID в приложение, сохрани ещё раз и отправь боту `/start`.

Приложение должно работать на компьютере. Не запускай один и тот же токен одновременно в другой программе. Для публикации карточки в канал боту нужны права администратора на публикацию.

## Проверка и границы выпуска

Пройдены 494 автоматических теста, проверка известных уязвимостей и проверка интерфейса через Windows UI Automation. Живые сценарии Spotify/Twitch, донат-сервисов, OBS, доставки Telegram и обновления уже установленной программы не объявляются проверенными этими тестами.

Облачное хранение и серверная часть в этот выпуск не входят. Яндекс-версия не обновляется. Для музыки в эфире необходимо учитывать права на записи и правила используемых сервисов; подписка музыкального сервиса сама по себе не подтверждает права на публичную трансляцию.
