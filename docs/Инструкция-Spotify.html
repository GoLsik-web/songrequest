Как подключить Spotify к приложению заказа музыки

Это займёт минут десять и делается один раз. Ничего программировать не нужно — только пройти по шагам и скопировать одну строчку.

Зачем это. Spotify не разрешает чужим программам управлять твоей музыкой просто так. Нужно один раз завести на сайте Spotify «пропуск» для приложения и дать этому пропуску доступ. Пропуск создаётся на твоём аккаунте и живёт у тебя — никто, кроме тебя, им пользоваться не сможет.

Что понадобится:

  • Аккаунт Spotify с подпиской Premium. Без неё управлять музыкой нельзя — это ограничение самого Spotify, обойти его невозможно.
  • Браузер.

Шаг 1
Зайти на сайт для разработчиков Spotify

Открой: developer.spotify.com/dashboard

Нажми кнопку входа и войди тем же самым аккаунтом Spotify, в котором ты слушаешь музыку на стриме. Это важно: если войти другим аккаунтом, приложение будет управлять чужой музыкой, а не твоей.

Если Spotify попросит принять условия для разработчиков — прими их. Возможно, попросит подтвердить адрес почты: сделай это, иначе следующий шаг не откроется.

Шаг 2
Создать «пропуск»

На открывшейся странице нажми зелёную кнопку Create app. Появится форма:

ПолеЧто вписать
App nameЗаказ музыки
название любое, его видишь только ты
App descriptionЗаказ треков зрителями
тоже любое
Redirect URIсм. ниже — самое важное поле

Redirect URI — это адрес, куда Spotify вернёт тебя после разрешения. Скопируй строчку ниже целиком, без пробелов в начале и в конце:

http://127.0.0.1:8977/callback

Вставь её в поле и обязательно нажми кнопку Add справа от поля — строка должна прыгнуть в список под полем. Если не нажать Add, Spotify её не запомнит.

Здесь чаще всего ошибаются. Адрес должен совпадать символ в символ. Не localhost вместо 127.0.0.1 — Spotify их больше не считает одинаковыми. Не https, а http. Не потеряй /callback в конце и не добавь / после него.

Ниже, в списке Which API/SDKs are you planning to use?, поставь галочку Web API. Остальные галочки не нужны.

Поставь галочку согласия с условиями и нажми Save.

Шаг 3
Скопировать Client ID

Тебя перебросит на страницу приложения. Нажми Settings справа вверху.

Найди строку Client ID — это набор букв и цифр вроде 4f8c2b1e9a7d43c6b0e5f2a1c3d4e5f6. Нажми рядом кнопку копирования.

Рядом будет ссылка View client secret — она нам не нужна, приложение работает без секрета. Не открывай её и никому не показывай.

Client ID — не пароль, но и не то, чем стоит светить в чате. Просто вставь его в приложение и закрой страницу.

Шаг 4
Вставить Client ID в приложение

  1. Запусти songrequest.exe. Откроется чёрное окно — не закрывай его, пока работает приложение. Заодно откроется вкладка браузера с панелью управления. Если не открылась — адрес написан в чёрном окне, обычно это http://127.0.0.1:8977
  2. В панели, в карточке Spotify, найди поле Client ID, вставь скопированное и нажми «Сохранить Client ID».
  3. Нажми «Подключить Spotify».
  4. Откроется страница Spotify со списком того, что приложение просит разрешить. Нажми Agree.
  5. Тебя вернёт на страницу с надписью «Готово». Вкладку можно закрыть.

Шаг 5
Проверить, что всё работает

Вернись в панель. Вверху должна гореть зелёная лампочка Spotify, а в карточке Spotify — твоё имя и слово Premium.

Если так и есть — открывай файл «Чек-лист-проверки» и иди по нему. Там уже проверяем саму работу приложения.

Если что-то пошло не так

В панели каждая ошибка показывается с коротким кодом вроде SP-04. Назови этот код тому, кто делает приложение — по нему сразу понятно, где искать. Вот самые частые:

КодЧто случилосьЧто делать
CFG-01Client ID не вставленВернись к шагу 3
SP-02Spotify не принял входОткрывай вход только из панели и не держи две вкладки входа сразу
SP-03Вход не завершилсяПочти всегда адрес из шага 2 отличается от нужного. Проверь его заново
SP-04Доступ слетелНажми «Подключить заново»
SP-05Нет PremiumПроверь, что вошёл тем аккаунтом, где оплачена подписка
SP-06Spotify нигде не открытОткрой Spotify и включи любой трек, чтобы оно стало активным
SP-07Spotify не отвечаетПроверь интернет, приложение попробует само ещё несколько раз
Отдельно про адрес. Если при запуске в панели появилось предупреждение, что порт 8977 занят и приложение работает на другом, — вернись в настройки приложения на сайте Spotify (шаг 2), нажми Edit и добавь тот адрес, который показала панель. Старый можно оставить, адресов может быть несколько.

Как прислать лог

  1. В панели, в карточке Диагностика, поставь галочку «Подробный лог».
  2. Повтори то действие, которое не сработало.
  3. Нажми «Выгрузить лог» — скачается один .zip.
  4. Отправь этот файл и назови код ошибки, который был в панели.

В архиве только записи работы приложения и настройки. Пароли, ключи доступа и твой Client ID туда не попадают — они вырезаются автоматически.
