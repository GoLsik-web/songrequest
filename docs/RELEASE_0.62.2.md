# 0.62.2 — метка донат-заказа и исправление обновлятора

- Донат становится заказом музыки только при достаточной сумме и метке в начале сообщения: `!музыка название трека` или `!музыка ссылка`.
- Метку можно изменить в настройках донатов. По умолчанию, в том числе после обновления, используется `!музыка`. Пустое поле возвращает это значение.
- Обычные донаты без метки больше не запускают поиск музыки. Правило общее для DonationAlerts, DonatePay и DonateX.
- Исправлена установка обновления, когда программа и папка данных находятся на разных дисках. Новый файл сначала подготавливается рядом с программой; при ошибке подготовки прежняя программа остаётся на месте.

Обновление проверяется вручную кнопкой «Проверить обновления». Если старый обновлятор сообщает, что вернул прежнюю версию, полностью выйдите через трей и замените `songrequest.exe` файлом из архива. Настройки хранятся отдельно.

Полный набор автоматических тестов и проверки синтаксиса изменённого JavaScript прошли. Живые донаты и обновление между дисками на компьютере пользователя этим выпуском не объявляются проверенными.
